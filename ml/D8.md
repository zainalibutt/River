## Architecture and inference

Keep the original `385 -> 512 -> 512 -> 512 -> 256` 128-bucket PReLU network.
Add one shared holding head: **`65 -> 16 -> 1`, PReLU, 1,074 parameters**.
Its last linear layer starts at zero. Add its residual to the holding's bucket
prediction. Train trunk and head jointly. Both player positions share the head.

Inputs are bucket prediction, position, log SPR; 19 local static features;
5 opponent range blocker features; and 19 pooled feature means from EACH range,
ordered as own/opponent. The static features include midpoint expected-strength
percentile, made category, river-category mean/spread, draw flags and exact out
counts, relative ranks, suitedness, board suit counts, board pairing, rank overlap
and the highest available flush-suit blocker. Dynamic features are max/min removed
single-card mass, union removed mass, and removed top-decile/draw mass. Shared
holdings are counted once. Blocked holdings return zero, and empty ranges are finite.

Potential is **exact hand-category mean/std across the 46 legal rivers**, not
showdown-percentile spread. This cheaper, coarser proxy is explicitly separate
from expected-strength percentile. Features use no teacher values or hidden cards.

No raw suit IDs enter the model. All 24 suit permutations are tied analytically:
after undoing their holding permutation, augmented inputs are identical. The TS test
checks the complete augmentation orbit with asymmetric ranges, including blockers
and pools. Explicitly materialising these duplicates would not change the loss.

`turnResidualLeaf(model)` is an opt-in adapter for `perTurnShowdown`. It caches up
to 64 prepared turn boards. Internal inference scratch is reused synchronously;
returned holding arrays remain valid after later calls. Production defaults do
not change.

0.1. Same trunk initial weights for a seed, independent but identical shuffle
