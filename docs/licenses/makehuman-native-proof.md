The first proof uses the system pack's high-poly eyes, eyebrow007,
eyelashes02, bob01 and young_caucasian_female2 skin, plus Dress01's
toigo_halter_dress_midi garment. Faceunits01 supplies the bounded blink, smile
and frustration shape-key source. Before a generated character is shipped,
the selected sources must remain reproducible from these recorded packs and
the web export must pass the project's asset budgets.
